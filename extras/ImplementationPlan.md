## Phase 1: Settings objects

### Step 1.1 — AbstractSerializableSettings + PnuCohortArgs [x]

**Goal:** The base class and the first concrete settings object.

**Files**
- `R/SettingsObjects.R` — `AbstractSerializableSettings` R6 class (adapted from CohortMethod; attribute in roxygen), `PnuCohortArgs` R6 class, exported `createPnuCohortArgs()` factory

**`createPnuCohortArgs()` arguments:**
| Argument | Type | Default | Meaning |
|----------|------|---------|---------|
| `targetCohortId` | int | — | cohort_id for treatment A |
| `comparatorCohortId` | int | — | cohort_id for treatment B (switcher index events) |

| `includedCovariateConceptIds` | int[] | `c()` | concept IDs to include (empty = all) |
| `washoutPeriod` | int | 365 | days of observation required before cohort start |
| `maxCohortSize` | int | 0 | 0 = no limit |

**Tests:** `tests/testthat/test-SettingsObjects.R` — round-trip JSON, validation errors on bad inputs.

## Phase 4: Simulation

### Step 4.1 — simulatePnuData() [x]

**Goal:** Simulate a `PnuData` object with known treatment effect and covariate structure, so that statistical steps can be tested without a real database.

**Files**
- `R/Simulation.R` — `createSimulationArgs()` (R6 + factory); `simulatePnuData(simulationArgs)` returning a `PnuData`

**`createSimulationArgs()` key arguments:**
- `nSwitchers`, `nComparatorsPerSet` — population size controls
- `nExposureSets` — number of sets (1 = pure ACNU)
- `nCovariates`, `prevalenceBase`, `prevalenceDiff` — covariate structure
- `logRr` — true log hazard ratio for the outcome
- `seed`

**Tests:** `tests/testthat/test-Simulation.R` — returns valid `PnuData`; with `logRr = 0` the crude HR is near 1.0 in large samples.

**Depends on:** 1.2

## Phase 6: Time-conditional propensity score

### Step 6.1 — fitTcps() [ ]

**Goal:** Fit a conditional logistic regression (CLR) stratified by exposure set to estimate P(switch | covariates).

**Files**
- `R/Tcps.R` — `createTcpsArgs()` (R6 + factory); `fitTcps(population, pnuData, tcpsArgs)` using `Cyclops::createCyclopsData()` with `modelType = "clr"` and `stratumId = exposure_set`; returns population with `propensityScore` column

**Key `createTcpsArgs()` arguments:**
- `prior` — Cyclops prior specification
- `control` — Cyclops control specification
- `excludedCovariateConceptIds`, `includedCovariateConceptIds`
- `maxCohortSizeForFitting`

**Tests:** `tests/testthat/test-Tcps.R` — on simulated data with a known covariate difference, AUC of fitted TCPS > 0.6.

**Depends on:** 5.1

## Phase 7: Matching

### Step 7.1 — matchOnTcps() [ ]

**Goal:** Greedy nearest-neighbour matching of switchers to comparators within each exposure set.

**Files**
- `R/Matching.R` — `createMatchingArgs()` (R6 + factory); `matchOnTcps(population, matchingArgs)` returning population with `stratumId` column (matched-set id)

**Key `createMatchingArgs()` arguments:**
- `caliper` (fraction of SD of log-PS; default 0.2)
- `caliperScale` (`"standardized logit"` or `"logit"`)
- `maxRatio` (int; 0 = variable ratio)
- `allowReverseMatch` (logical; should comparators ever "win"?)

**Tests:** `tests/testthat/test-Matching.R` — matched population has ≤ maxRatio comparators per switcher; no cross-set matches.

**Depends on:** 6.1

## Phase 9: Outcome models

### Step 9.1 — fitOutcomeModel() [ ]

**Goal:** Fit a stratified Cox PH model for the matched sets.

**Tests:** `tests/testthat/test-OutcomeModels.R` — on simulated data with known `logRr = log(2)`, estimated `logRr` within 2 SEs of truth.

## Decisions log

| Step | Decision | Choice | Rationale |
|------|----------|--------|-----------|
| 0.1 | EmpiricalCalibration not installed locally | Moved to Suggests; will promote to Imports in Step 12.1 when code actually uses it | `devtools::document()` and `check()` load all Imports; can't load an uninstalled package |
| 0.1 | styler not installed locally | Skipped; file written to tidy-verse 2-space standard by hand | styler is a dev convenience; add to dev dependencies before Step 1.1 |
| 0.1 | VignetteBuilder removed until vignettes exist | Removed knitr from VignetteBuilder; kept in Suggests | R CMD check warned "Vignette dependency required without any vignettes" |
| 0.2 | Exposure-set definition in fixture | Days on A (120 = ~4 months, 270 = ~9 months) rather than calendar months | Integer days avoids ambiguity in date arithmetic; tests can assert exact values |
| 1.1 | Default for concept-ID vectors | `integer(0)` not `c()` in factory signature | `c()` evaluates to NULL in R, which fails `assertIntegerish(null.ok = FALSE)` |
| 1.1 | EmpiricalCalibration stays in Suggests | No change yet | Still not installed; jsonlite added to Imports instead |
| 1.2 | "slots" in plan means Andromeda tables | cohorts/outcomes/exposureSets are DuckDB tables, not S4 slots | CovariateData has no extra S4 slots; all data is stored in the DuckDB database via Andromeda |
| 1.2 | class() assignment must be single string | class(x) <- "PnuData" not c("PnuData","CovariateData") | Setting multiple class strings strips S4 semantics; the hierarchy is already encoded in setClass(contains=) |
| 2.1 | Set 0 comparators not implemented | Deferred to StudyPopulation step (5.1) | Finding set-0 comparator index dates requires calendar-date matching, not era-history lookup; out of scope for the reference implementation |
| 2.1 | do.call(rbind, c(rows, list(make.row.names=FALSE))) broken | Replaced with explicit empty-list guards + rownames(d)<-NULL | The make.row.names trick misbehaves when rows is empty or length-1 |
| 2.2 | querySql returns upper-case column names | snakeCaseToCamelCase = FALSE + manual rename in the returned tibble | snakeCaseToCamelCase=TRUE would produce camelCase, requiring column name changes throughout |
| 2.2 | expect_no_error() does not accept info argument | Replaced with try() + expect_false(inherits(..., "try-error")) | This version of testthat disallows extra ... in expect_no_error |
| 2.3 | "ACNU pairing" scope | Only the switcher/target identity is tested here; full pipeline equivalence (matched comparators, outcome model) deferred to Phase 5+ | set-0 comparator index dates require calendar matching not yet implemented |
| 3.1 | exposureSetDefinition not in PnuCohortArgs | Added as direct arg to getDbPnuData() (default "time") | Plan's Step 1.1 arg list for PnuCohortArgs has no such field; adding it there would change a ticked step |
| 3.1 | Cyclops / ResultModelManager moved to Suggests | Not used until Phase 6+/10+; R CMD check warned about unused Imports | cli and pillar added to Imports (used in PnuData::show via ::) |
| 4.1 | outcomeBaseRate and followUpDays added to plan args | Both needed for the exponential survival model; plan listed only logRr without specifying the rate scale | outcomeBaseRate = P(event | comparator, followUpDays) is the most interpretable parameterisation |
| 4.1 | toJson() precision fixed (digits = 15) | jsonlite default (4 decimal places) silently corrupted logRr on round-trip | All float fields in SimulationArgs must survive JSON serialization; fix applied to AbstractSerializableSettings |
| 3.1 | cohortId = -1 in getDbCovariateData | Skips cohort_definition_id WHERE clause; no extra column needed in #pnu_cohorts | Verified via FeatureExtraction SQL template pattern |
| 3.1 | Andromeda preserves R attributes | metaData attr survives saveAndromeda/loadAndromeda; no extra table needed | Verified with small live test |
