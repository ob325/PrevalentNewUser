# PrevalentNewUser: Prevalent New-User Cohort Design for OMOP CDM Data

Implements the prevalent new-user (PNU) cohort design (Suissa et al.
2017 [doi:10.1002/pds.4117](https://doi.org/10.1002/pds.4117) ) for data
in the OMOP Common Data Model. The PNU design allows the reference
treatment group to have already been exposed when index dates are
defined, complementing CohortMethod which implements the
active-comparator new-user design.
