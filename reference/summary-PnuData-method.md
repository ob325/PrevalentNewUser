# Summarise a PnuData object

Summarise a PnuData object

## Usage

``` r
# S4 method for class 'PnuData'
summary(object, ...)
```

## Arguments

- object:

  A \`PnuData\` object.

- ...:

  Ignored.

## Value

A list of class \`summary.PnuData\` with components: \`metaData\`,
\`switcherCount\`, \`comparatorCount\`, \`exposureSetCount\`,
\`outcomeCount\`, \`covariateCount\`, \`covariateValueCount\`.
